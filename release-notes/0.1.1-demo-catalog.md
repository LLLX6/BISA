# BISA 0.1.1 — Demo catalog and phone preview

## العربية

- إضافة 6 محلات تجريبية تغطي ولايات مسقط الست.
- إضافة 24 منتجاً و6 باقات و6 إعلانات مرتبطة بالمناطق.
- كل سجل تجريبي موسوم في قاعدة البيانات ويمكن حذفه من زر إداري واحد بعد تأكيد صريح.
- إضافة معاينة هاتف مستقلة على GitHub Pages تدعم العربية والإنجليزية، اختيار المنطقة، السلة ذات المتجر الواحد وPWA داخل مسار المستودع.
- لا تدعي المعاينة العامة إرسال طلب حقيقي؛ الطلبات الفعلية تتطلب خادم BISA.

## English

- Added 6 demo stores covering all six Muscat wilayats.
- Added 24 products, 6 bundles and 6 area-targeted advertisements.
- Every demo entity is tagged in the database and can be removed by one audited admin action after an exact confirmation phrase.
- Added a standalone GitHub Pages phone preview with Arabic/English, area filtering, a one-store cart and repository-subpath PWA support.
- The public preview does not claim to submit real orders; transactional ordering requires the BISA server.
